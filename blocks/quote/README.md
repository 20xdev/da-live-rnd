# quote

Custom **quote** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No authored variations. Styling follows the content:

- Quotation only: plain inset blockquote (WKND unstyled text component).
- Quotation + attribution row: the decorator adds `quote-has-attribution`, which renders
  the WKND "quote" text style (grey panel, serif quotation with yellow rule, sans-serif attribution).
